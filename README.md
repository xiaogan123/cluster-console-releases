# 网站集群管理后台 · 下载与更新

管理自己的网站工作区，查看站点状态、数据与更新记录，并选择 Claude / Codex 会话接管或本机 CLI 托管。

本仓库提供公开发行文件，不包含用户站点、凭据、工作区或私有源码。

## 已安装用户

点击客户端右上角 **软件更新**，检查并安装最新版本。更新会保留本机工作区；不会因为升级而开启自动更新任务或自动发布。

## 首次使用

在 [Releases](https://github.com/xiaogan123/cluster-console-releases/releases/latest) 下载对应平台的文件：

| 平台 | 文件与使用方式 |
|---|---|
| macOS 13 及以上 · Apple Silicon（M 系列） | `*_darwin-aarch64.app.tar.gz`，解压后将其中的应用放入“应用程序” |
| Windows x64 | `*_Windows_x64_setup.exe`，运行安装程序 |

当前发行不提供 Intel Mac 版本。更新优先复用上述文件，不另外生成 macOS DMG。Windows 安装文件同时用于应用内更新。

客户端、Hugo 与传统站点再生器随包提供，无需另装 Python 或单独下载工具包。若选择 CLI 托管，需要在本机安装并登录对应的 Claude Code 或 Codex CLI；已有 AI 会话也可以按应用内接入说明接管。

## 开始用

第一次打开时创建或接入自己的工作区。应用不附带站点数据；可复制引导提示词，让自己的 AI 根据站点清单和现有工具协助配置。站点结构体检会展示支持情况，由用户决定是否改造；旧站与 Hugo 站可并存。

更新文件有客户端验证的更新签名。macOS 应用使用临时签名，尚未使用 Apple Developer ID 签名或通过 Apple 公证；Windows 应用尚未做 Authenticode 签名，首次运行可能出现系统提示。

## 数据与执行范围

工作区、凭据与本地缓存保存在用户电脑上。选择数据刷新、AI 任务、IndexNow 提交或部署时，会按已配置的账号与服务发送完成该操作所需的数据。请只接入自己信任的工作区命令和服务。

自动排期、周报、周审与自动发布由用户自行开启；这些任务需要电脑开机且守护进程运行。会话接管与 CLI 托管的具体用法见客户端引导页、托管页和提示词页。
