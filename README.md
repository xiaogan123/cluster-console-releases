# 网站集群管理后台 · 下载

AI 接入的通用网站集群托管客户端。一处看全部站点的健康与更新节奏，让本机的
Claude Code / Codex 以受控方式接手内容更新。

> 本仓库只放安装包。

## 下载

到 [**Releases**](../../releases/latest) 页下载对应平台的安装包：

| 平台 | 文件 |
|---|---|
| macOS · Apple 芯片（M 系列） | `*_aarch64.dmg` |
| macOS · Intel | `*_x64.dmg` |
| Windows 10/11 · 64 位 | `*_x64-setup.exe` |

**无需安装 Python 或任何运行时**，安装包自包含。

## 首次打开

安装包未做代码签名，第一次打开需要放行一次：

- **macOS**：双击被拦后，去 `系统设置 → 隐私与安全性`，在底部点「仍要打开」。
- **Windows**：SmartScreen 弹窗点「更多信息 → 仍要运行」。

## 开始用

应用第一次打开是空的 —— 它不带任何站点数据，你管理的是自己机器上的一份「工作区」
（站点清单 / 更新台账 / 动作定义）。首屏引导给了两种配置方式：手动写三份 JSON，
或者复制一段提示词交给你自己的 AI 会话代劳。

具体怎么配、怎么把 AI 接进来，见应用内的引导页与设置页。

## 说明

- 应用与你的数据全部在本机运行，不上传任何内容。
- 它会执行你在工作区里配置的命令，请只连你信任的工作区。
